# Sitio Web de Reporte en información al Ciudadano para la Gestión de Residuos Sólidos en Riohacha

## Objetivo

Desarrollar un prototipo web funcional que permita consultar horarios de recolección de residuos sólidos y registrar reportes ciudadanos sobre problemáticas relacionadas con acumulación y retrasos en la recolección de basura, ademas de reportar puntos críticos en la ciudad de Riohacha, La Guajira.

## Problema que soluciona

En diferentes sectores de Riohacha se presentan dificultades relacionadas con la acumulación de residuos sólidos, falta de información clara sobre horarios de recolección y ausencia de canales digitales organizados para que los ciudadanos puedan reportar incidencias.

Este prototipo busca apoyar la gestión informativa del servicio mediante una herramienta sencilla que permite consultar horarios y registrar reportes ciudadanos.

## Tecnologías usadas

HTML5  
CSS3  
JavaScript  
LocalStorage del navegador  
GitHub para almacenamiento del código fuente  

## Cómo ejecutar el prototipo

No es necesario instalar ningún programa en especifico.

Solo se se necesita acceso a internet y un navegador web como Google Chrome, Microsoft Edge o Mozilla Firefox.

## Funciones desarrolladas

Consulta de horarios de recolección por barrio.

Registro de reportes ciudadanos.

Validación básica de campos obligatorios.

Almacenamiento de reportes usando LocalStorage.

Visualización de reportes registrados.

Interfaz básica adaptable a dispositivos móviles.
